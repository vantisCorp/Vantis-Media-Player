# Vantis Media Player Examples

This directory contains example code demonstrating various features and capabilities of Vantis Media Player.

## Available Examples

### Basic Usage

#### `simple_player.rs`
A minimal example showing how to create a basic media player.

**Features demonstrated:**
- Creating a player instance
- Loading media files
- Basic playback controls
- Event handling

**Run:**
```bash
cargo run --example simple_player
```

### Input & Controls

#### `keyboard_shortcuts_example.rs`
Demonstrates keyboard shortcut implementation for playback control.

**Features demonstrated:**
- Keyboard event handling
- Playback control shortcuts
- Volume control
- Seeking functionality
- Subtitle toggling
- Fullscreen control

**Shortcuts included:**
- Space: Play/Pause
- →/←: Seek forward/backward 5s
- ↑/↓: Volume up/down
- M: Mute/Unmute
- F: Toggle fullscreen
- S: Toggle subtitles
- Q: Quit

**Run:**
```bash
cargo run --example keyboard_shortcuts
```

Here's a basic template for creating your own example:

```rust
use vantis_core::Player;

fn main() {
    // Create player
    let mut player = Player::new();
    
    // Load media
    player.load("path/to/video.mp4")
        .expect("Failed to load video");
    
    // Your code here...
    
    // Cleanup
    player.stop();
}
```

## Troubleshooting

### Build Errors

**Problem**: `error: failed to compile example`
- **Solution**: Ensure Rust is up to date: `rustup update`

### Runtime Errors

**Problem**: `Failed to load video`
- **Solution**: Check file path and format

**Problem**: `No audio output`
- **Solution**: Check audio device permissions and configuration

### Plugin Issues

**Problem**: `Failed to load plugin`
- **Solution**: Verify WASM compilation and plugin manifest
