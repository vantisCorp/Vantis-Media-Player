# Roadmap

The development roadmap for Vantis Media Player outlines planned features, improvements, and milestones.

## Vision

Vantis Media Player aims to be the most versatile, performant, and developer-friendly media player for modern web applications. Our focus is on delivering exceptional playback quality, extensive format support, and seamless integration capabilities.

## Current Version: 2.0

### Completed Features
- React 18 integration
- TypeScript migration
- Plugin architecture
- WASM plugin support
- Flux state management
- PWA support
- HLS/DASH streaming
- DRM support
- Multi-audio tracks
- Subtitle support
