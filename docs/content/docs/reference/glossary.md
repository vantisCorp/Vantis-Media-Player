# Glossary

Key terms and concepts used throughout Vantis Media Player documentation.

## A

### Adaptive Bitrate Streaming (ABR)
A technique that dynamically adjusts video quality based on network conditions to provide smooth playback. Common implementations include HLS (HTTP Live Streaming) and DASH (Dynamic Adaptive Streaming over HTTP).

### API
Application Programming Interface. A set of rules and protocols for building and interacting with software applications.

### Aspect Ratio
The proportional relationship between the width and height of a video. Common aspect ratios include 16:9 (widescreen), 4:3 (standard), and 21:9 (ultrawide).

### Audio Codec
A method used to compress and decompress audio data. Common codecs include AAC, MP3, Opus, and FLAC.

## B

### Bitrate
The amount of data processed per unit of time, typically measured in bits per second (bps) or kilobits per second (kbps). Higher bitrates generally result in higher quality but require more bandwidth.

### Buffer
A temporary storage area that holds video data before playback. Buffers help prevent playback interruptions due to network latency.

### Browser Extension
A software extension that adds functionality to a web browser.

## C

### Codec
Short for "coder-decoder." A software or hardware tool that compresses and decompresses digital media.

### Container Format
A file format that can contain multiple streams of audio, video, and subtitles. Common containers include MP4, WebM, MKV, and AVI.

### CORS
Cross-Origin Resource Sharing. A security feature that allows or restricts web applications from making requests to domains other than their own.

### Custom Controls
User interface elements for controlling video playback that are custom-built rather than using the browser's default controls.

## D

### DASH
Dynamic Adaptive Streaming over HTTP. An adaptive bitrate streaming technology that works over standard HTTP servers.

### Decoder
Software or hardware that decompresses encoded media data for playback.

### DRM
Digital Rights Management. Technologies used to control access to copyrighted content.

## E

### Encoder
Software or hardware that compresses raw media data into a specific format.

### EME
Encrypted Media Extensions. A web API that provides a way to play DRM-protected content in browsers.

### Event
A system notification that occurs when a specific action or state change happens in the player.

### Event Listener
A function that waits for and responds to specific events.

## F

### FPS
Frames Per Second. The rate at which consecutive images (frames) are displayed in a video. Common frame rates include 24, 30, and 60 FPS.

### Flux
An application architecture pattern used in Vantis Media Player for state management, emphasizing unidirectional data flow.

### Fullscreen Mode
A display mode where the video player occupies the entire screen.

## G

### GPU
Graphics Processing Unit. Hardware that accelerates video decoding and rendering.

### GUI
Graphical User Interface. The visual interface through which users interact with the player.

## H

### HLS
HTTP Live Streaming. An adaptive bitrate streaming protocol developed by Apple.

### Hardware Acceleration
The use of specialized hardware (like GPU) to perform tasks more efficiently than general-purpose CPU.

### Hook
In React, a special function that lets you hook into React state and lifecycle features from function components.

## I

### Interface
In TypeScript, a structure that defines the shape of an object, including properties and methods.

### Integration
The process of incorporating Vantis Media Player into an existing application or system.

## J

### JavaScript
A programming language commonly used for web development, including the core logic of Vantis Media Player.

### JSX
A syntax extension for JavaScript that allows you to write HTML-like code in your JavaScript files.

### JSDoc
A markup language used to add type annotations and documentation to JavaScript code.

## K

### Keyframe
A frame in a video that contains the complete image, used as a reference point for compression.

## L

### Latency
The delay between a video signal being sent and received, typically measured in milliseconds.

### Library
A collection of pre-written code that developers can use to perform common tasks.

### Lifecycle
The series of states a component or player goes through from creation to destruction.

## M

### Manifest
A file (typically in M3U8 format for HLS or MPD for DASH) that describes the available video streams and their characteristics.

### Metadata
Data that provides information about other data, such as video title, duration, or codec information.

### MSE
Media Source Extensions. A web API that allows JavaScript to construct media streams for playback.

## N

### Native Plugin
A plugin written in a native language (C++, Rust, etc.) that extends the player's functionality.

### Node.js
A JavaScript runtime built on Chrome's V8 JavaScript engine, used for server-side development and build tools.

## O

### OOP
Object-Oriented Programming. A programming paradigm based on objects containing data and code.

### Open Source
Software whose source code is made available to the public, allowing anyone to view, modify, and distribute it.

## P

### Package Manager
A tool that automates the process of installing, updating, and managing software dependencies.

### PIP
Picture-in-Picture. A feature that allows playing video in a small, floating window while doing other tasks.

### Plugin
A software component that adds specific features or functionality to the player.

### Progressive Download
A method of delivering video where the file downloads sequentially and can be played as it downloads.

## R

### React
A JavaScript library for building user interfaces, used as the core framework for Vantis Media Player.

### Reflow
The process of the browser recalculating the layout of a web page.

### Responsive Design
An approach to web design that makes web pages render well on a variety of devices and screen sizes.

### Rendition
A specific quality version of a video in adaptive streaming, characterized by resolution, bitrate, and codec.

## S

### SDK
Software Development Kit. A collection of software development tools in one installable package.

### Seek
The action of moving to a specific point in the video timeline.

### SRT
SubRip Text. A subtitle file format that contains text-based subtitles with timing information.

### State
The data that a component or application stores and uses to determine its behavior and rendering.

### Stream
A continuous flow of media data over a network.

### Subtitle
Text displayed at the bottom of the screen that translates or transcribes the video's audio.

## T

### TypeScript
A typed superset of JavaScript that compiles to plain JavaScript, providing type safety and improved developer experience.

### Tauri
A framework for building desktop applications using web technologies.

### Transcoding
The process of converting media from one format to another.

## U

### UI
User Interface. The visual components through which users interact with the player.

### UMD
Universal Module Definition. A pattern for JavaScript modules that works in multiple module systems.

### URL
Uniform Resource Locator. The address of a resource on the internet.

## V

### Video Codec
A method used to compress and decompress video data. Common codecs include H.264 (AVC), H.265 (HEVC), VP9, and AV1.

### VOD
Video on Demand. A system that allows users to select and watch video content whenever they choose.

## W

### WASM
WebAssembly. A binary instruction format for a stack-based virtual machine that enables high-performance applications on web pages.

### Web Components
A set of web standards that allow for the creation of reusable custom elements.

### Web Worker
A JavaScript API that allows scripts to run in background threads, preventing the main thread from being blocked.

## X

### XML
eXtensible Markup Language. A markup language that defines a set of rules for encoding documents.

## Y

### Yarn
A package manager for JavaScript that is compatible with npm.

## Z

### Zero Trust Architecture
A security concept centered on the belief that organizations should not automatically trust anything inside or outside their perimeters.

## Related Concepts

### Adaptive Streaming
A technique that automatically adjusts video quality based on network conditions and device capabilities.

### Content Delivery Network (CDN)
A distributed network of servers that deliver content to users based on their geographic location.

### Cross-Platform
Software that can run on multiple operating systems or platforms.

### Responsive Design
Design that adapts to different screen sizes and devices.

### Single Page Application (SPA)
A web application that loads a single HTML page and dynamically updates content as the user interacts with it.
