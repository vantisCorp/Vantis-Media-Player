Getting Started

Welcome to Vantis Media Player! This guide will help you get up and running quickly.

System Requirements

  • Operating System: Linux, Windows, or macOS
  • Rust: 1.70.0 or later (for building from source)
  • GPU: Vulkan, DirectX 12, or Metal support
  • RAM: 4GB minimum, 8GB recommended
  • Storage: 500MB for installation

Installation

Build from Source

Clone the repository and build:

git clone https://github.com/vantisCorp/VantisMedia.git
cd VantisMedia
cargo build --release

The binary will be in target/release/vantis

Docker

Pull and run the Docker image:

docker pull vantismedia/vantis-player:latest
docker run -it --rm \
  -v /path/to/media:/media \
  vantismedia/vantis-player:latest

Release Binary

Download the latest release from GitHub:

wget https://github.com/vantisCorp/VantisMedia/releases/latest/download/vantis-linux.tar.gz
tar -xzf vantis-linux.tar.gz
./vantis

Quick Start

Play a media file using the CLI:

vantis play /path/to/video.mp4

Play with subtitles:

vantis play /path/to/video.mp4 --subtitles /path/to/subtitles.srt

Search and download subtitles automatically:

vantis play /path/to/video.mp4 --auto-subtitles


        
 Configuration

        
Vantis Media Player uses a TOML configuration file. Create ~/.config/vantis/config.toml:

        
[audio]
device = "default"
exclusive_mode = true
loudness_normalization = true

[video]
renderer = "auto"
hardware_acceleration = true
upscaling = "ai"

[subtitles]
auto_download = true
preferred_language = "en"
encoding = "utf-8"

[ui]
theme = "dark"
omnibar_shortcut = "Ctrl+K"


        

            
            Tip: Run vantis config --init to generate a default configuration file.
        


        
 Plugins

        
Install plugins from the marketplace:

        
vantis plugins install plugin-name


        
List installed plugins:

        
vantis plugins list


        
Enable/disable plugins:

        
vantis plugins enable plugin-name
vantis plugins disable plugin-name


        
 Keyboard Shortcuts

        
Default keyboard shortcuts:

        
    
            
  • Space - Play/Pause
    • 
            
  • ← / → - Seek backward/forward 10 seconds
    • 
            
  • ↑ / ↓ - Volume up/down
    • 
            
  • M - Mute/Unmute
    • 
            
  • F - Toggle fullscreen
    • 
            
  • S - Toggle subtitles
    • 
            
  • Ctrl+K - Open Omnibar
    • 
            
  • Q - Quit
    • 
        


        

            
            Note: You can customize keyboard shortcuts in the configuration file or via the UI.
