Architecture

Vantis Media Player is built with a modular, event-driven architecture designed for performance, extensibility, and maintainability.

System Overview

The player consists of 18 modules organized into core and advanced subsystems

Core Modules

vantis-core

Central coordination, event bus, state management, configuration, and zero-copy buffer pools

vantis-video

Hardware-accelerated decoding, GPU rendering, AI upscaling, HDR tone mapping

vantis-audio

Bit-perfect output, multi-format decoding, effects, loudness normalization

vantis-subtitles

Vantis Babel: Multi-source aggregation, hash matching, AI synchronization

vantis-ui

Liquid Glass framework, omnibar, smart controls, media library browser

vantis-plugins

WASM sandbox, host functions, lifecycle management, hot-reload

vantis-integrations

TMDB, Filmweb, Trakt.tv integration for metadata and watch history

vantis-cli

Command-line interface with play, subtitles, plugins, scan, config commands

Advanced Modules

vantis-ai

Video enhancement, scene detection, audio enhancement, smart subtitles, recommendations

vantis-streaming

Adaptive streaming, P2P, caching, recording, protocol support (HLS, DASH, RTSP)

vantis-advanced-audio

Room correction, HRTF virtualization, fingerprinting, visualization, multichannel

vantis-advanced-video

Stabilization, frame interpolation, denoising, color grading, comparison

vantis-advanced-ui

Picture-in-Picture, mini-player, theater mode, gestures, shortcuts

vantis-advanced-plugins

Marketplace, dependency management, enhanced sandbox, monitoring

vantis-advanced-testing

Property-based testing, fuzzing, performance regression, memory leak detection

vantis-advanced-docs

Interactive tutorials, video tutorials, API playground, examples gallery

vantis-advanced-build

Cross-compilation, release notes, deployment, rollback, health monitoring

vantis-advanced-analytics

Usage analytics, crash reporting, performance monitoring, feedback, A/B testing

Data Flow

1. Media Input

User selects media file or stream URL

2. Core Processing

VantisCore coordinates via EventBus, manages state and buffer pools

3. Video Pipeline

Decode → GPU Render → AI Upscale → HDR Tone Map → Display

4. Audio Pipeline

Decode → Effects → Loudness Normalize → Bit-Perfect Output

5. Subtitle Pipeline

Aggregate → Hash Match → Parse → AI Sync → Display

6. UI Rendering

Liquid Glass renders GPU-accelerated interface with controls

Design Principles

Zero-Cost Abstractions

Use Rust's zero-cost abstractions for performance without sacrificing safety

Zero-Copy Memory

Direct DMA transfers from storage to GPU memory, pre-allocated buffer pools

GPU Acceleration

Leverage WGPU for cross-platform GPU rendering (Vulkan/DX12/Metal)

Event-Driven

Decoupled components communicate via EventBus for flexibility

WASM Sandbox

Plugins run in isolated WASM sandbox for security and stability

Modular Design

Each module is independent and can be used standalone or combined

Technology Stack

  • Language: Rust (Nightly) for zero-cost abstractions and safety
  • GPU: WGPU for cross-platform GPU rendering
  • Video: FFmpeg for hardware-accelerated decoding
  • Audio: Symphonia for multi-format decoding, CPAL for output
  • AI/ML: Burn, Candle, ndarray for AI features
  • WASM: Wasmtime for plugin sandbox
  • Async: Tokio for non-blocking I/O
  • UI: Iced for modern GUI framework
