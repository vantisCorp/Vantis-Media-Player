Core API

VantisCore

The main player engine that coordinates all subsystems.

pub fn new(config: Config) -> Result<VantisCore>

Create a new VantisCore instance with the given configuration.

config
Player configuration including audio, video, subtitles, and UI settings
Returns: Result<VantisCore> - The initialized player core or an error

pub async fn stop(&self) -> Result<()>;

Mute or unmute audio.
