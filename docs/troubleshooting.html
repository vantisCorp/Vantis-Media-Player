Troubleshooting

Common issues and solutions for Vantis Media Player.

Installation Playback Audio Video Subtitles Plugins Performance

Installation Issues

Build Fails with "linker not found"

Error: error: linker `link.exe` not found

Solution: Install the appropriate linker for your platform:
  • Linux: sudo apt install build-essential
  • macOS: xcode-select --install
  • Windows: Install Visual Studio Build Tools

FFmpeg Not Found

Error: Failed to find FFmpeg libraries

Solution: Install FFmpeg development libraries:
  • Linux: sudo apt install libavcodec-dev libavformat-dev libavutil-dev
  • macOS: brew install ffmpeg
  • Windows: Download from ffmpeg.org

Playback Issues

Video Won't Play

Player shows error when trying to play video file.

Solution:
  1. Check if file format is supported (MP4, MKV, AVI, WebM)
  2. Verify file is not corrupted
  3. Check logs: vantis play --verbose file.mp4
  4. Try with different codec settings

Playback Stutters

Video plays but with stuttering or frame drops.

Solution:
  1. Disable hardware acceleration: vantis config set video.hardware_acceleration false
  2. Reduce video quality
  3. Close other applications
  4. Check system resources: vantis stats

Seeking is Slow

Player takes long time to seek to different positions.

Solution:
  1. Enable keyframe seeking in config
  2. Use faster storage (SSD vs HDD)
  3. Reduce buffer size

Audio Issues

No Sound

Video plays but there's no audio output.

Solution:
  1. Check volume is not muted: vantis volume get
  2. Verify audio device: vantis audio list-devices
  3. Check system audio settings
  4. Try different audio backend

Audio Out of Sync

Audio and video are not synchronized.

Solution:
  1. Enable audio sync: vantis config set audio.sync true
  2. Adjust sync offset: vantis audio sync-offset 100
  3. Try different audio decoder

Audio Distortion

Audio sounds distorted or crackling.

Solution:
  1. Disable exclusive mode: vantis config set audio.exclusive_mode false
  2. Adjust buffer size
  3. Disable audio effects
  4. Check audio driver updates

Video Issues

Green Screen

Video displays as green screen.

Solution:
  1. Switch GPU backend: vantis config set video.renderer vulkan
  2. Update GPU drivers
  3. Disable hardware acceleration
  4. Try software decoding

Wrong Colors

Video colors appear incorrect or washed out.

Solution:
  1. Adjust color space settings
  2. Enable HDR tone mapping
  3. Check display color profile
  4. Try different color grading preset

AI Upscaling Not Working

Video not being upscaled as expected.

Solution:
  1. Check AI models are downloaded: vantis ai list-models
  2. Verify upscaling is enabled: vantis config set video.upscaling ai
  3. Ensure GPU supports AI operations
  4. Check logs for errors

Subtitle Issues

Subtitles Not Displaying

Subtitles loaded but not shown on screen.

Solution:
  1. Check subtitles are enabled: vantis subtitles enable
  2. Verify subtitle file format is supported
  3. Check encoding (try UTF-8)
  4. Adjust subtitle position/size

Subtitles Out of Sync

Subtitle timing doesn't match video.

Solution:
  1. Use AI sync: vantis subtitles sync --ai
  2. Manual offset: vantis subtitles offset 2.5
  3. Adjust playback speed temporarily

Garbled Characters

Subtitle text displays as garbled characters.

Solution:
  1. Detect encoding: vantis subtitles detect-encoding file.srt
  2. Convert to UTF-8: vantis subtitles convert --to utf-8 file.srt
  3. Set encoding in config

Plugin Issues

Plugin Won't Load

Plugin fails to load with error message.

Solution:
  1. Check plugin is compiled for WASM
  2. Verify plugin.toml is valid
  3. Check permissions are declared
  4. View plugin logs: vantis plugins logs plugin-name

Plugin Crashes Player

Player crashes when plugin is loaded.

Solution:
  1. Check plugin for infinite loops
  2. Verify memory usage is reasonable
  3. Test plugin in isolation
  4. Report issue to plugin author

Hot Reload Not Working

Plugin changes not reflected after reload.

Solution:
  1. Ensure hot-reload is enabled: vantis plugins enable-hot-reload plugin-name
  2. Check file watcher is running
  3. Verify plugin is recompiled
  4. Try manual reload: vantis plugins reload plugin-name

Performance Issues

High CPU Usage

Player uses excessive CPU resources.

Solution:
  1. Disable AI features
  2. Reduce video quality
  3. Disable unnecessary effects
  4. Use hardware acceleration

High Memory Usage

Player consumes too much RAM.

Solution:
  1. Reduce buffer size
  2. Disable caching
  3. Close unused plugins
  4. Check for memory leaks

Slow Startup

Player takes long time to start.

Solution:
  1. Disable auto-loading plugins
  2. Reduce library scanning
  3. Clear cache: vantis cache clear
  4. Check for slow operations in startup
Getting More Help:
  • Check logs: vantis logs --verbose
  • Search GitHub Issues
  • Create a new issue with detailed information
  • Join community discussions
When Reporting Issues: Please include:
  • Vantis Media Player version
  • Operating system and version
  • Hardware specifications
  • Steps to reproduce
  • Error messages and logs
