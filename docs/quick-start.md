# Quick Start

## 3 Lines to Vantis

```bash
curl -fsSL https://get.vantis.dev | sh    # Install
vantis play your-video.mp4                 # Play
# Enjoy your media! 🎬                     # Done!
```

---

That's it! Vantis is now playing your media with:
- ✅ Hardware acceleration
- ✅ Auto-detected subtitles
- ✅ Optimal quality settings
