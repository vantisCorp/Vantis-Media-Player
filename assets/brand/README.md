# Vantis Media Player - Brand Assets

This directory contains all brand assets for Vantis Media Player.

## Assets

### Logos

- **logo.svg** - Main logo (512x512)
  - Full gradient with sound waves
  - Dark background optimized
  - Primary brand identity element

- **icon-dark.svg** - Icon for dark backgrounds (64x64)
  - Minimalist play button
  - Dark background
  - Favicon, app icon

- **icon-light.svg** - Icon for light backgrounds (64x64)
  - Minimalist play button
  - Light background
  - Favicon, app icon

### Banners

- **banner.svg** - Project banner (1280x320)
  - Full width header
  - Includes title, tagline, and badges
  - Used in documentation and social media

### Social Media

- **social-preview.svg** - Open Graph preview (1280x640)
  - Social media sharing preview
  - Optimized for Twitter, Facebook, LinkedIn
  - Open Graph metadata

## Usage

### In Documentation

```markdown
![Vantis Media Player Logo](assets/brand/logo.svg)
```

### In HTML

```html
<img src="assets/brand/logo.svg" alt="Vantis Media Player Logo" width="256" height="256">
```

### As Favicon

```html
<link rel="icon" href="assets/brand/icon-dark.svg" type="image/svg+xml">
```

### In Social Media

```html
<meta property="og:image" content="https://vantis.media/assets/brand/social-preview.svg">
<meta name="twitter:image" content="https://vantis.media/assets/brand/social-preview.svg">
```

## Guidelines

### Usage Rules

1. **Don't** modify the logo colors
2. **Don't** stretch or distort the logo
3. **Don't** add shadows or effects
4. **Do** use appropriate size for context
5. **Do** maintain aspect ratio
6. **Do** provide sufficient whitespace

### Minimum Sizes

- **Print**: 1 inch (72px) wide
- **Web**: 32px wide
- **Mobile**: 24px wide

### Spacing

- Minimum padding around logo: 1x logo height
- Minimum margin between logo and text: 2x logo height

## File Formats

### SVG (Recommended)

- **Advantages**: Scalable, small file size, editable
- **Use**: Logos, icons, illustrations
- **Tools**: Adobe Illustrator, Figma, Inkscape

### PNG (Fallback)

- **Advantages**: Broad compatibility
- **Use**: Fallback for older browsers
- **Tools**: Adobe Photoshop, GIMP

### WebP (Optimized)

- **Advantages**: Smaller file size, good quality
- **Use**: Web images, backgrounds
- **Tools**: Squoosh, TinyPNG
