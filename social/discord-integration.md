## 🤖 Bot Commands

Vantis Bot provides useful commands:

| Command | Description |
|---------|-------------|
| `/help` | Show available commands |
| `/play <url>` | Play media in voice channel |
| `/stats` | Show player statistics |
| `/plugin <name>` | Search plugin marketplace |
| `/version` | Check latest version |
| `/docs <topic>` | Search documentation |
| `/translate <text>` | Translate message |
| `/bug <description>` | Create bug report |
