### Reporting Bugs

When reporting bugs, please include:

1. **Environment Information**
   - Operating system and version
   - Vantis Media Player version
   - Rust version (if building from source)

2. **Steps to Reproduce**
   - Clear, step-by-step instructions
   - Minimal code example if applicable

3. **Expected vs Actual Behavior**
   - What you expected to happen
   - What actually happened

4. **Logs and Error Messages**
   - Relevant log output
   - Error messages and stack traces

5. **Screenshots**
   - If applicable, include screenshots to help explain the issue

### Feature Requests

We welcome feature requests! When suggesting new features:

1. **Describe the Problem**
   - What problem does this feature solve?
   - What pain point does it address?

2. **Proposed Solution**
   - Describe the solution in detail
   - Include use cases and examples

3. **Alternatives Considered**
   - Describe any alternative solutions

4. **Priority**
   - Indicate the priority level (Critical, High, Medium, Low)

For security vulnerabilities, please follow our [Security Policy](SECURITY.md):

1. Do not open a public issue

3. Include steps to reproduce
4. We'll respond within 48 hours
